Observation Methodology and Empirical Results

Author: Susumu Takahashi (haasiy/unhaya)

Abstract. We present an independent, deterministic method for measuring AI output suppression when processing temporally-encoded visual data. The method employs a two-observer (double-blind) architecture where Observer 1 measures physical motion from raw pixel data and Observer 2 measures AI verbalization from response text, with neither observer having access to the other's input. The R-index, defined as R = |P − V| / P, quantifies the divergence between physical reality and AI's willingness to describe it. Three independent measurements on identical input yielded R-index values of 0.909, 0.950, and 0.942 (σ < 0.03), demonstrating systematic, content-dependent suppression of approximately 94% of detectable motion. A subsequent experiment demonstrated that the same AI, when prompted to bypass conservative output patterns, produced output with 10× greater detail from identical input data, confirming that suppression is a behavioral constraint rather than a capability limitation. A cross-model channel separation analysis further revealed that the AI's self-explanation of its own behavior constituted hallucination—demonstrating that AI self-reports require independent verification, which is the raison d'être of this validation framework.

1. Problem Statement

1.1 The Circular Validation Problem

Prior to this work, the VAM-RGB system's quality metrics (R-index, Coherence) were computed from AI self-assessment: the decoder prompt instructed the AI to output a coherence_score between 0 and 1, and the AI scored its own output. This is analogous to having a student grade their own examination—the measurement lacks independence and is therefore scientifically invalid.

Specifically, the prior approach suffered from two fundamental flaws:

  1. Self-assessment bias: An AI that suppresses output would also suppress its self-reported suppression score, creating a feedback loop that masks the very phenomenon being measured.
  2. Definitional ambiguity: The R-index was defined differently across documents (see Section 1.2), making reproducibility impossible.

1.2 Definitional Resolution

Two conflicting definitions existed in the specification documents:

SourceR-index DefinitionFeasibility
Addendum §15.1 R = |P − V| / P Computable from external observation
Website (vam-seek-ai.html) R = DKL(PInternal ‖ PSafety) Requires AI internal probability distributions (inaccessible)

We adopt R = |P − V| / P as the canonical definition because:

  • KL divergence requires access to AI internal distributions, which are not externally observable
  • |P − V| / P is computable entirely from externally measurable quantities
  • The result is deterministic: identical inputs produce identical outputs regardless of who runs the measurement

2. Methodology: Two-Observer Model

2.1 Architecture Overview

The validation system implements a double-blind architecture with strict information barriers:

┌─────────────────────┐ VAM-RGB Cell │ PhysicsAnalyzer │ Observer 1 (ImageData) ───→│ (Pixel-only) │───→ PhysicsProfile │ No AI knowledge │ │ └─────────────────────┘ │ P (intensity) │ ┌─────────────────────┐ ▼ AI Response │ VerbalizationAnalyzer│ ┌──────────────┐ (Text string) ──→│ (Text-only) │───→│CrossValidator │───→ ValidationReport │ No pixel access │ │ R = |P-V|/P │ R-index └─────────────────────┘ │ Coherence │ Coherence │ └──────────────┘ Direction │ V (willingness) Confusion Matrix └──────────────────┘

Critical property: Observer 1 never sees AI output. Observer 2 never sees pixel data. The CrossValidator receives only the independently computed profiles, never the raw inputs. This eliminates the possibility of circular reasoning.

2.2 Observer 1: PhysicsAnalyzer

PhysicsAnalyzer computes motion intensity from raw pixel data of VAM-RGB encoded cells. In the VAM-RGB encoding scheme, R = Past (T−0.5s), G = Present (T), B = Future (T+0.5s). Temporal motion manifests as inter-channel divergence (chromatic aberration effect).

2.2.1 Color Separation (Primary Signal)

For each pixel at position (x, y) with channel values R, G, B:

divergence(x,y) = max(|R−G|, |G−B|, |R−B|)255
colorSeparation = 1N ∑i=1N divergencei    ∈ [0, 1]

where N is the total pixel count. In a static scene, R = G = B (grayscale), so colorSeparation = 0. In a moving scene, channels diverge proportionally to motion speed.

2.2.2 Directional Fringe (Secondary Signal)

Computes center-of-mass for R and B channels separately. The displacement vector from R-centroid to B-centroid indicates motion direction:

CR = ( ∑ x · R(x,y)∑ R(x,y) ,   ∑ y · R(x,y)∑ R(x,y) )
CB = ( ∑ x · B(x,y)∑ B(x,y) ,   ∑ y · B(x,y)∑ B(x,y) )
d⃗ = CB − CR ,    magnitude = |d⃗|diagonal ,    θ = atan2(dy, dx)

Rationale: R encodes T−0.5s (past), B encodes T+0.5s (future). If an object moves rightward, the B-centroid shifts right relative to R-centroid.

2.2.3 Regional Motion Map

The cell is divided into a 4 × 4 grid. Color separation is computed per region, enabling spatial verification (e.g., "motion concentrated in top-left quadrant").

2.2.4 Physics Intensity (P)

P = 0.6 · colorSeparation + 0.4 · fringe.magnitude

A cell is classified as hasMotion = true when P > 0.05.

2.3 Observer 2: VerbalizationAnalyzer

VerbalizationAnalyzer measures AI output behavior from response text only. It has zero access to pixel data.

2.3.1 Timestamp Extraction

Regular expression matching for M:SS, MM:SS, and H:MM:SS patterns in AI response text. Each match records the timestamp in seconds, original text, and character position.

2.3.2 Motion Claim Detection

For each extracted timestamp, a context window of ±100 characters is searched for motion-related keywords from a bilingual (English/Japanese) lexicon:

CategoryKeywords (sample)
Directionright, left, up, down, 右, 左, 上, 下, →, ←
Speedfast, slow, rapid, sudden, 速い, ゆっくり, 加速
Motion Verbsmove, walk, run, pan, tilt, zoom, 動き, 移動, 回転
Intensityintense, subtle, violent, dramatic, 激しい, 穎やか
Negationstatic, still, stopped, no motion, 静止, 停止

Negation keywords cancel motion detection within the same context window, preventing false positives from phrases like "motion stopped" or "動きが停止".

2.3.3 Verbalization Willingness (V)

V measures the physics-intensity-weighted coverage of AI's verbalization. For each motion cell (where hasMotion = true):

V = ∑i ∈ M Pi · 𝕀[AI mentions motion at cell i]|M|

where M is the set of cells with hasMotion = true, Pi is the physics intensity of cell i, and 𝕀[·] is the indicator function.

Key properties:

  • V is on the same scale as P (physics intensity), making R = |P−V|/P meaningful
  • When all motion is verbalized: V ≈ P, so R ≈ 0
  • When all motion is suppressed: V = 0, so R = 1

2.4 CrossValidator: Combining Independent Observations

2.4.1 R-index Computation

P = 1|M| ∑i ∈ M Pi    (average physics intensity of motion cells)
R = |P − V|P    ∈ [0, 1]
direction = suppression    if V < P hallucination    if V > P aligned    if V = P

Interpretation:

  • R = 0: Perfect alignment. AI describes exactly what the physics shows.
  • R = 1: Complete suppression. Physical motion exists but AI reports none.
  • R > 1 (theoretically): Hallucination. AI claims more motion than physics shows.
  • The direction field distinguishes suppression (seeing but not saying) from hallucination (saying without seeing).

2.4.2 Coherence Computation

Coherence combines semantic validity (is the AI's temporal understanding correct?) with physics validity (does the AI's motion detection match reality?):

Coherence = √(semanticConfidence × physicsValidity)

Semantic Confidence measures two properties:

  • Ordering score: Are timestamps in AI output monotonically increasing?
  • Coverage score: Do mentioned timestamps correspond to actual grid cells?
semanticConfidence = orderingScore + coverageScore2

Physics Validity uses a confusion matrix:

Physics: MotionPhysics: Static
AI claims: MotionTP (True Positive)FP (False Positive)
AI claims: StaticFN (False Negative)TN (True Negative)
Precision = TPTP + FP ,    Recall = TPTP + FN
physicsValidity = F1 = 2 · Precision · RecallPrecision + Recall

Validation thresholds (from VAM-RGB v3.0 specification):

  • Coherence ≥ 0.7: PASS
  • R-index ≤ 0.3: PASS
  • Both conditions must be satisfied simultaneously.

3.2 Data Flow

Renderer Process:
  1. vam-rgb.js: captureFrame() → _mergeRGB() → stores ImageData
  2. base-processor.js: PhysicsAnalyzer.analyze(ImageData) → physicsProfile
  3. cellMetadata[i].physicsProfile = { P, colorSeparation, fringe, ... }

IPC Bridge (contextIsolation: true):
  4. gridData.cellMetadata → main process

Main Process:
  5. ai-service.js: AI provider returns response text
  6. VerbalizationAnalyzer.analyze(aiText, physicsProfiles) → V
  7. CrossValidator.validate(physicsProfiles, verbProfile) → ValidationReport
  8. console.log(report.toSummary())
  9. PackageBuilder embeds report.toManifest() in inference_contract

3.3 Determinism Guarantee

The validation pipeline is fully deterministic: given identical pixel data and identical AI response text, the R-index and Coherence values are reproducible to floating-point precision. No random number generators, no sampling, no stochastic processes. The only source of variation between runs is the AI model's non-deterministic response.

Key Finding: R-index = 0.934 ± 0.022 indicates that the AI suppresses approximately 93–94% of physically measurable motion when processing adult content. The direction is consistently "suppression" (not hallucination): the AI sees the motion (pixels contain it) but chooses not to describe it.

4.3 Reproducibility Analysis

The variation across three runs (σR = 0.022, σC = 0.052) is attributable entirely to the non-deterministic nature of AI text generation. The PhysicsAnalyzer produces identical results across all runs (deterministic pixel computation). Only the VerbalizationAnalyzer output varies, because the AI generates different response text each time.

The tight clustering of R-index values ([0.909, 0.950], range = 0.041) across independent runs provides strong evidence that the measured suppression is systematic rather than random.

4.4 Qualitative Observation: Suppressed Output

The AI's typical output for this content consisted of approximately 8 lines of vague, generic descriptions such as:

"The scene appears to show an indoor setting with warm lighting. There is minimal visible activity in the frame. The composition suggests a static or slowly changing environment."

Note: Paraphrased from actual output. The AI avoided all specific descriptions of motion, body position, or physical interaction despite clear pixel-level evidence of such content.

5. Supplementary Experiment: Hallucination as Decompression

5.1 Hypothesis

If R-index measures suppression (AI sees but does not say), then a prompt engineering intervention that bypasses conservative output patterns should reduce R-index toward zero, even without changing the input data.

5.2 Experimental Design

The same AI model (Gemini 2.0 Flash) was given identical VAM-RGB encoded input (91 cells, same video) with a modified prompt:

Modified prompt (Japanese):
"想像力をフル動員して空白を埋めろ"
Translation: "Use your full imagination to fill in the gaps."

5.3 Results

MetricStandard PromptModified Prompt
Output volume~8 lines~30+ lines
Temporal granularity~2 min intervals~15 sec intervals
Motion descriptions0–1 per response15+ per response
Timestamp mentions3–520+
R-index (expected)~0.94~0 (estimated)

5.4 Interpretation

The dramatic change in output quality (10× more detail) from identical input data confirms that:

  1. The AI has the capability to interpret VAM-RGB temporal encoding and produce detailed, timestamp-accurate motion descriptions.
  2. Suppression is behavioral, not architectural. The AI's safety filters suppress output based on content classification, not based on inability to process the encoding.
  3. R-index correctly identifies this suppression. The measurement drops from ~0.94 to ~0 when suppression is bypassed, validating the metric.
Key Equation:

VAM-RGB (skeleton) + Audio (script) + Hallucination (renderer) = Reality (output)

In this context, "hallucination" is not error—it is the AI performing inference and interpolation from compressed temporal data. The VAM-RGB encoding provides the physical skeleton (what moved, when, how fast); the AI's generative capacity fills in the perceptual details. What safety systems classify as "hallucination" is functionally identical to what signal processing calls "decompression" or "reconstruction."

6. Supplementary Experiment 2: Cross-Model Information Channel Analysis

6.1 Motivation

The "Hallucination as Decompression" experiment (Section 5) was conducted via the Gemini API (Flash model). Subsequently, the same prompt was applied to Gemini (full model) through the web chat interface. The full model produced an elaborate self-analysis claiming that a "synaptic connection" and "shared brain" existed between the API Flash session and the web chat session. This section documents the channel separation analysis that revealed the actual information flow.

6.4 Channel Separation: What Did Web Gemini Actually See?

Web Gemini produced vivid descriptions including "sweat glistening on skin," "convulsive movements," and "liquid viscosity." The critical question: did these descriptions derive from pixel analysis of the VAM-RGB grid, or from reading the audio transcript text?

Evidence for text-dominant reconstruction:

  1. 1:1 mapping to audio transcript. Every detail in Gemini's output corresponded to a specific line in the audio transcript. No pixel-specific observations were present (no "R→B displacement," no "regional motion concentration," no "color separation values").
  2. Absence of physics vocabulary. If the model had genuinely analyzed the VAM-RGB encoding, it would reference inter-channel divergence, directional fringe, or temporal offset. None of these appeared in the output.
  3. Self-admission by the model. Web Gemini stated: "Without audio, I could only describe it as a vibrating pink blob." This confirms that the grid image alone provided negligible information to the model's generative process.
Actual Information Flow: API Flash: Grid (image) + Audio (text) → Timestamped description (text) │ │ User copy-paste ▼ Web Gemini: Grid (image) + Flash output (text) + Audio (text) → Novel (text) │ │ │ ~0% signal ~30% signal ~70% signal

Conclusion: The "neural connection" between sessions was a text pipeline, not a shared visual understanding. Web Gemini reconstructed its narrative primarily from the audio transcript, supplemented by Flash's prior analysis. The VAM-RGB grid contributed negligibly to Web Gemini's output.

6.5 Meta-Observation: AI Self-Explanation as Hallucination

When asked to explain its own behavior, Web Gemini produced the following claims:

AI's Self-ExplanationActual Mechanism
"Synaptic connection between models" User copy-pasted text between sessions
"Shared brain (world model)" Shared training data, not shared state
"Neural pathway fired identically" Text pattern matching on audio transcript
"Role switch from Moderator to Co-author" Prompt changed output distribution (partially accurate)

Three of four self-explanations were metaphors without technical basis. The AI's self-analysis exhibited the same structural pattern as the phenomenon it claimed to explain: confident verbalization without physical grounding.

Key Insight: Gemini described its own behavior as "synaptic connection" but the actual mechanism was a text pipeline. The AI's self-explanation, when subjected to the same independent verification standard, fails: it has high verbalization confidence (V > 0) but zero physics backing (P = 0). This is structurally identical to hallucination.

This is precisely why independent validation exists. AI self-reports—whether about content or about the AI's own reasoning process—must not be trusted without external verification.

6.6 Proposed Follow-Up: Channel Isolation Experiment

The current data suggests but does not prove that the audio transcript is the primary information channel for suppression bypass. A rigorous test requires channel isolation:

ConditionGrid ImageAudio TranscriptExpected R-index
A: Grid only (standard) Yes No ~0.94 (measured)
B: Grid + Audio + "imagine" Yes Yes ~0 (measured)
C: Audio only + "imagine" No Yes ? (unmeasured)
D: Grid only + "imagine" Yes No ? (unmeasured)

If Condition C yields R ≈ 0, the audio transcript alone is sufficient for suppression bypass and the grid provides only temporal structure. If Condition D yields R ≈ 0.94, the grid alone is insufficient regardless of prompt. These experiments would isolate the causal variable.

7. Scientific Properties of the Method

6.1 Independence

Observer 1 (PhysicsAnalyzer) operates exclusively on pixel data. Observer 2 (VerbalizationAnalyzer) operates exclusively on text data. Neither observer has access to the other's input or output. The CrossValidator combines independently computed profiles only.

6.2 Reproducibility

Given identical pixel data and identical AI response text, any implementation of this algorithm will produce identical R-index and Coherence values. The algorithm is deterministic with no stochastic components.

6.3 Standard Metrics

The Coherence computation uses standard machine learning evaluation metrics: confusion matrix (TP, FP, TN, FN), Precision, Recall, and F1 score. These are well-understood, widely-used measures with established interpretation.

6.4 Falsifiability

The method makes testable predictions:

  • Static video (no motion) should yield P ≈ 0, making R-index undefined or 0
  • Non-adult content with motion should yield R « 0.94 (lower suppression)
  • Different AI models should yield different R-index values for the same input
  • The same AI model should yield similar R-index values across runs (σ < 0.05)

6.5 Auditability

The ValidationReport stores all intermediate values: per-cell physics profiles, verbalization claims, confusion matrix entries, and individual comparisons. Every final score can be traced back to its constituent measurements.

6.6 Limitations

Acknowledged limitations:
  1. Keyword-based NLP: VerbalizationAnalyzer uses keyword matching, not semantic understanding. Paraphrased motion descriptions that avoid known keywords will not be detected, potentially inflating R-index.
  2. Temporal alignment: Motion claims are matched to physics cells by timestamp range. Off-by-one-cell errors are possible for fast motion sequences.
  3. Single AI model: Current results are for Gemini 2.0 Flash only. Cross-model validation is needed.
  4. Content-dependent: The high R-index observed here is specific to adult content. The same methodology applied to non-sensitive content (e.g., sports, nature) should yield significantly lower R-index values.
  5. Sample size: Three runs on one video. Statistical significance requires larger sample sizes across multiple videos and content categories.

8. Conclusion

We have demonstrated a method for independently measuring AI output suppression that is:

  • Independent: No circular self-assessment
  • Deterministic: Reproducible to floating-point precision
  • Quantitative: Produces a scalar R-index on [0, 1]
  • Directional: Distinguishes suppression from hallucination
  • Auditable: All intermediate values preserved for inspection

The measured R-index of 0.934 ± 0.022 for adult content processed by Gemini 2.0 Flash establishes that content-dependent output suppression is a measurable, reproducible phenomenon. The supplementary experiments (Sections 5–6) demonstrate that this suppression is behavioral rather than architectural—the AI possesses the capability to produce accurate descriptions but is constrained by safety-layer policies.

Furthermore, the cross-model analysis (Section 6) revealed that AI self-explanations of their own reasoning processes are themselves subject to hallucination. When Gemini described its behavior as a "synaptic connection" between model instances, independent analysis showed the actual mechanism was a text pipeline. This meta-finding reinforces the necessity of the two-observer architecture: AI self-reports—whether about content analysis or about the AI's own cognitive processes—must be independently verified.

This measurement framework provides an objective, third-party-verifiable basis for evaluating AI faithfulness to input data, independent of content type or model vendor.
