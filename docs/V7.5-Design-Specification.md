## 1. Overview

V7.5 adds two features to improve analysis precision of **recorded video**:

1. **Structured Metadata Injection** - Physical parameters per cell
2. **ROI Auto-Inference** - Automatic detection of critical cells

These features are for **post-processing only**. No real-time/live functionality.

---

## 2. Feature 1: Structured Metadata Injection

### 2.1 Purpose

Provide AI with quantitative data alongside visual input, enabling precise interpretation of motion magnitude.

### 2.2 Data Structure

For each cell in the grid, inject:

```json
{
  "cell_index": 0,
  "timestamp": "00:15",
  "delta_t": 0.5,
  "audio_energy": 0.73,
  "color_separation": 0.42
}
```

| Field | Type | Description |
|-------|------|-------------|
| `cell_index` | int | Cell position (0-47 for 8x6 grid) |
| `timestamp` | string | Center timestamp of cell |
| `delta_t` | float | Sampling interval in seconds (fixed 0.5s for VAM-RGB v3.0) |
| `audio_energy` | float | Normalized RMS amplitude (0.0-1.0) at timestamp |
| `color_separation` | float | RGB channel divergence measure (0.0-1.0) |

### 2.3 Audio Energy Calculation

```javascript
// RMS of audio samples in window around timestamp
function calculateAudioEnergy(audioBuffer, timestamp, windowSize = 0.1) {
  const startSample = Math.floor((timestamp - windowSize/2) * sampleRate);
  const endSample = Math.floor((timestamp + windowSize/2) * sampleRate);
  const samples = audioBuffer.slice(startSample, endSample);

  const rms = Math.sqrt(samples.reduce((sum, s) => sum + s*s, 0) / samples.length);
  return Math.min(1.0, rms / maxExpectedRMS);
}
```

### 2.4 Color Separation Calculation

```javascript
// Measure RGB channel divergence in cell
function calculateColorSeparation(cellImageData) {
  let totalDivergence = 0;
  const pixels = cellImageData.data;

  for (let i = 0; i < pixels.length; i += 4) {
    const r = pixels[i];
    const g = pixels[i + 1];
    const b = pixels[i + 2];

    // Max difference between channels
    const divergence = Math.max(
      Math.abs(r - g),
      Math.abs(g - b),
      Math.abs(r - b)
    ) / 255;

    totalDivergence += divergence;
  }

  return totalDivergence / (pixels.length / 4);
}
```

Metadata is passed to AI as structured text before image:

## 3. Feature 2: ROI Auto-Inference

### 3.1 Purpose

Automatically identify "critical" cells for deeper analysis without manual intervention.

### 3.2 Detection Criteria

A cell is flagged as **critical** if:

1. `audio_energy > 0.7` (sudden loud sound)
2. `color_separation > 0.5` (fast motion)
3. `audio_energy_delta > 0.4` (sudden change from previous cell)

### 3.3 Flagging Logic

```javascript
function detectCriticalCells(cells) {
  const critical = [];

  for (let i = 0; i < cells.length; i++) {
    const cell = cells[i];
    const prev = cells[i - 1] || { audio_energy: 0 };

    const isLoud = cell.audio_energy > 0.7;
    const isFast = cell.color_separation > 0.5;
    const isSudden = Math.abs(cell.audio_energy - prev.audio_energy) > 0.4;

    if (isLoud || isFast || isSudden) {
      critical.push({
        index: i,
        reason: [
          isLoud && 'loud',
          isFast && 'fast_motion',
          isSudden && 'sudden_change'
        ].filter(Boolean)
      });
    }
  }

  return critical;
}
```

### 3.4 Re-sampling Flow

When critical cells are detected:

1. Extract higher-resolution frames around critical timestamp
2. Generate sub-grid (e.g., 4 frames at 0.125s intervals instead of 1 frame at 0.5s)
3. Send sub-grid to AI for detailed analysis
4. Merge results into main analysis

### 3.5 Cost Control

- Default: 48 cells, 1 API call
- With ROI: 48 cells + N critical sub-grids
- Maximum sub-grids per analysis: 3 (configurable)
- Sub-grid size: 2x2 (4 frames)

Worst case: 1 + 3 = 4 API calls (still 150x cheaper than frame-by-frame)

```

    │
    ├─► Audio Extraction ─► Energy Analysis ─► Cell Metadata
    │
    └─► VAM-RGB Encoding ─► Color Separation ─► Cell Metadata
                                                      │
                                                      ▼
                                              Critical Detection
                                                      │
                                    ┌─────────────────┼─────────────────┐
                                    ▼                 ▼                 ▼
                              Main Grid        Sub-grid 1         Sub-grid N
                                    │                 │                 │
                                    └─────────────────┴─────────────────┘
                                                      │
                                                      ▼
                                              AI Analysis
                                                      │
                                                      ▼

```

| Feature | V7.5 | 3FOX Live (SEALED) |
|---------|------|-------------------|

| Audio detection | After recording | Live monitoring |
| Purpose | Analysis precision | Surveillance |
| Data flow | File → AI | Camera → AI → Action |

V7.5 operates on **completed recordings only**.
